ZOMATO DATA ANALYTICS
A data analysis project using real Zomato restaurant data from across India.

Cleaned and analyzed a dataset of 60,000+ restaurants

Explored top restaurant chains, popular cuisines, and most active cities

Visualized restaurant ratings, price ranges, delivery trends, and customer votes

Used Python libraries: pandas, seaborn, matplotlib, plotly

Goal: Understand customer preferences and business trends in the food industry
